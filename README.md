# nacenovani-licence

Veřejný seznam stavu licencí ke sdíleným datům pluginu **nacenovani-kros** (CUP Elektro s.r.o.).

Soubor `stav-licenci.json` je podepsaný klíčem poskytovatele dat; plugin ho při načtení dat stáhne a podle něj
pozná odvolanou nebo prodlouženou licenci. Obsahuje jen čísla licencí, stav a datum platnosti – žádná data,
jména ani e-maily. Ruční úprava souboru podpis zneplatní.

Aktualizace: `ceniky_db.py licence odvolej|obnov|prodluz|zverejni` vytvoří nový `stav-licenci.json`
